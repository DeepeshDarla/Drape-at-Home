# The Draper — Free Website

Static, responsive website for The Draper, Mysuru.

## Deployment

This repo is connected to Netlify for continuous deployment: pushes to `main`
build and deploy automatically. The production domain is
https://www.thedraper.in — the underlying Netlify subdomain
(https://thedraper.netlify.app) still serves the same build and redirects to
the production domain.

- Netlify → Forms has the `home-visit` form enabled; confirm email notifications are on.
- Netlify project settings → Build & deploy → Continuous deployment shows the
  GitHub link and build status.

## Before launch
- Replace remote Unsplash imagery with The Draper's own project/product photos when available.
- Connect Google Search Console and Google Business Profile after launch.
